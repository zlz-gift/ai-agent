# 示例笔记（笔记检索工具的演示素材）

> 这个文件是 `search_notes` 工具的**示例数据**，用来演示"模型自主检索本地笔记"的效果。
> 你自己的笔记放在同目录下即可，但 `.gitignore` 已配置为**只提交 `sample.md`**，个人笔记不会被推送。

## LangGraph 与 LangChain 的分工

LangChain 负责组件与链路（Prompt、模型、解析器、工具），LangGraph 负责把流程组织成带状态、可分支、可循环的图。
流程越复杂、分支和循环越多，越适合用 LangGraph 管理；单轮工具调用用 `bind_tools` 就够。

## 记忆的分层

短期记忆保存最近若干轮对话原文，保证上下文连贯；长期记忆把早期对话压缩成摘要持久化，控制上下文长度与 token 成本。
外部记忆指向量库或笔记文件，按需检索后再放进上下文，即 RAG 的思路。

## 工具调用的执行流程

观察任务 → 判断是否需要工具 → 生成工具调用（名称 + 参数）→ 执行工具 → 把结果回填给模型 → 生成最终回答。
一轮不够时模型可以继续发起新的工具调用，直到不再需要工具为止，这个循环就是 ReAct 的核心思想。
